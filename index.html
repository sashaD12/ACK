Нарезачка

Локальная программа для нарезки своих длинных видео в вертикальные ролики для YouTube Shorts и TikTok. Распознавание речи, подбор фрагментов, субтитры, описание, теги и превью выполняются на компьютере пользователя.

Публикация в YouTube и TikTok возможна только через официальные API после входа в свой аккаунт. Пользователь загружает собственный контент.
