Условия использования

Дата обновления: 16 октября 2026.

Нарезачка — локальное приложение для обработки видео, которое пользователь устанавливает и запускает на своем компьютере.

1. Назначение

Сервис помогает нарезать собственные длинные видео в короткие вертикальные ролики, подготовить описание, теги и превью и при желании опубликовать их через официальные API YouTube и TikTok.

2. Контент

Пользователь загружает только материалы, на которые у него есть права. Запрещено использовать программу для перезалива чужих фильмов, музыки и роликов без разрешения правообладателя.

3. Аккаунты платформ

Вход в YouTube и TikTok выполняется через OAuth этих платформ. Пользователь сам отвечает за соблюдение правил YouTube и TikTok, включая авторские права, рекламу и ограничения на контент.

4. Ответственность

Приложение предоставляется «как есть». Автор не отвечает за блокировки аккаунтов, отказ в модерации, потерю файлов или результат публикации.
